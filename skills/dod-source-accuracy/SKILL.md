# DoD項目: 出典の正確性

脚注・参考文献が実際に読んだURLか。自己申告の数値(star数・性能数値等)は「未検証」と明記されているか。複数の対象を比較する表で同種の指標(star数・バージョン等)を扱う場合、対象ごとに取得時点・精度・未検証表記の扱いが揃っているか。

## 使い方

成果物(記事・ドキュメント・設計案・PR)を完了とする前に、上記の観点を満たしているか確認する。満たしていなければ、完了として報告する前に修正する。
